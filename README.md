# 🌱 Crop Disease Detection System

This project is an AI-powered system that detects crop diseases using deep learning and provides recommendations based on soil parameters.

## 🚀 Features
- CNN-based crop disease detection
- FastAPI backend
- Soil analysis (pH, NPK, moisture)
- Disease severity prediction
- Crop recommendation system

## 🛠 Tech Stack
- Python, FastAPI
- TensorFlow / Keras
- HTML, CSS

## 📂 Project Structure
- backend/ → ML model + API
- frontend/ → UI (HTML, CSS)
- requirements.txt → dependencies

## ▶️ How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run backend:
   uvicorn backend.app:app --reload

3. Open browser:
   http://127.0.0.1:8000
